# LERCO CMMS — منظومة متابعة أعمال الصيانة

نظام محلي لتخطيط الصيانة وإدارتها لقسم التخطيط والبرمجة (الشركة الليبية الإماراتية لتكرير النفط).
Python + Streamlit (شبكة LAN) + SQLite بوضع WAL.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```
- قاعدة البيانات `cmms.db` تُنشأ بجوار `database.py` (أو بالمتغير `CMMS_DB_PATH`).
- الترقية تلقائية عند التشغيل (أعمدة وجداول جديدة بلا فقد بيانات). **خذ نسخة من `cmms.db` قبل أي ترقية.**

## الاختبارات
```bash
pip install -r requirements-dev.txt
pytest -q
```
تعمل على قاعدة مؤقتة ولا تلمس بياناتك.

## ملفات المشروع
| الملف | الوظيفة |
|---|---|
| `app.py` | الواجهات والصفحات |
| `database.py` | قاعدة البيانات والقواعد والدورة المستندية |
| `tir_form.py` | نموذج تقرير التفتيش المبسّط |
| `monthly.py` | التقارير الشهرية ومؤشر التحسين |
| `report.py` | ملفات Excel |
| `docs/SYSTEM_STATE.md` | وصف المنظومة وقراراتها الحالية |
| `CLAUDE.md` | قواعد المشروع لمن يطوّره (Claude أو غيره) |

## قواعد مهمة
- لا ترفع `cmms.db` ولا أي نسخة منها إلى GitHub (البيانات خاصة بالشركة).
- اختيار الدور من الشريط العلوي يحدد واجهة القسم فقط، ولا يمنح صلاحية Admin.
- أنشئ حساب المسؤول الأول محلياً عبر `python create_admin.py`؛ كلمة المرور لا تُحفظ في المستودع.
- جلسة Admin مستقلة ومحددة بثماني ساعات، وتُتحقق منها قاعدة البيانات عند كل تعديل إداري.
